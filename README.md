# KEMIX (كيميكس) — لعبة تعلّم البرمجة التفاعلية

تطبيق سطح مكتب مستقل لأنظمة Windows مبني باستخدام **Electron + React 19 + TypeScript + Vite**. يجمع بين أسلوب التلعيب والتدرّج الممتع (Gamification) والهوية الأصلية لـ **KEMIX** المستوحاة من الصقر المصري الأسطوري **"حورس"**، بألوان تجمع بين الذهبي الملكي والتركواز السيبراني والكحلي الداكن.

---

## 🦅 هوية وشخصية KEMIX (Brand & Mascot)

- **الشخصية الرئيسية (Mascot):** الصقر المصري الذكي **"حورس"**، رفيق اللاعب طوال رحلة التعلّم:
  - يُشجع عند النجاح وإتمام التحديات بنغمات احتفالية.
  - يُقدم تلميحات ذكية لشرح أسباب الخطأ وتوجيه اللاعب.
  - يدعم اللاعب عند نفاد القلوب بكلمات تحفيزية.
- **التصميم والألوان:** ألوان ذهبية ملكية (`#fbbf24`) مع تركواز سماوي (`#00e5ff`) على خلفية كحلية داكنة، مع عناصر تحكّم ثلاثية الأبعاد بلمسة تفاعلية.
- **اللغة والاتجاه:** الواجهة باللغة العربية مع دعم RTL كامل 100%، بينما تُعرض الأكواد والمصطلحات البرمجية الإنجليزية بالاتجاه الصحيح LTR مع شرح عربي وافٍ ونطق صوتي ومفهومي مدمج.

---

## 🌐 نظام العوالم والمراحل واللفلات (Worlds Hierarchy)

تم تقسيم رحلة التعلّم إلى هيكل ديناميكي مرن:

1. **عالم التفكير المنطقي والخوارزميات (Logic & Algorithms):** فهم خطوات الحل المتسلسل، المدخلات والمخرجات، وترتيب خطوات الخوارزمية.
2. **عالم أساسيات بايثون والأوامر البرمجية (Python Programming Basics):** دالة العرض `print()`، التعامل مع السلاسل النصية والأرقام، ومعارك الزعماء.
3. **عالم المتغيرات وأنواع البيانات (Variables & Data Types):** تخزين البيانات في الذاكرة، الأعداد الصحيحة `int`، النصوص `str`، والقيم المنطقية `bool`.
4. **عالم الشروط والعمليات المنطقية (Conditions & Logic):** اتخاذ القرارات البرمجية عبر `if` و `else`.
5. **عالم الحلقات والتكرار (Loops & Iterations):** تكرار المهام المعقدة عبر `for` و `while`.
6. **عالم الدوال وإعادة الاستخدام (Functions & Modularity):** إنشاء واستدعاء الدوال المخصصة.
7. **عالم القوائم وهياكل البيانات (Lists & Data Structures):** إدارة وتنظيم مجموعات البيانات.
8. **عالم المشروعات وصيد الأخطاء (Projects & Debugging):** مشروعات برمجية متكاملة وتصحيح الثغرات.

## 🎮 نظام اللعب والمكافآت (Gamification)

- **القلوب (Hearts):** 5 قلوب تستهلك عند الخطأ، تتجدد تلقائياً كل 10 دقائق، أو مجاناً عبر تدريبات التقوية، أو بالشراء عبر عملات كيميكس.
- **نقاط الخبرة (XP) والمستويات:** كسب XP مع كل إجابة، ومكافأة +15 XP للدرس المثالي و +100 XP لمعركة الزعيم.
- **عملات كيميكس الذهبية (Coins):** جمع العملات واستخدامها في تعبئة القلوب والتلميحات.
- **الكومبو والشعلة (Combo & Streak):** عداد كومبو متصاعد للإجابات المتتالية بنغمات صوتية تزداد حدتها، وشعلة الحماس اليومي.
- **المهام اليومية (Daily Quests):** 3 مهام يومية للمطالبة بمكافآت إضافية.
- **الأوسمة والإنجازات (Badges):** مثل "أول كود لكيميكس"، "درس مثالي"، "قاهر الزعماء"، "مهندس الأكواد الحية".
- **لوحة المتصدرين (Weekly Leaderboard):** دوري أسبوعي بين اللاعبين مع منطقة تأهل وصعود.

## 💻 محرر الأكواد والتشغيل الآمن (KEMIX Code Sandbox)

- محرر أكواد متكامل ومخصص للمبتدئين بلغة بايثون.
- بيئة تشغيل آمنة ومعزولة (Isolated Execution Engine) مع حماية ضد الحلقات اللانهائية وتجاوز الوقت (Timeout Protection).
- شاشة مخرجات (Terminal Console) حقيقية تعرض `stdout` و `stderr` مع توقيت التنفيذ بالمللي ثانية وملاحظات الصقر حورس.

---

## 🛠️ لوحة إدارة المحتوى الديناميكية (KEMIX Admin CMS)

- **إنشاء وتعديل العوالم والوحدات والدروس:** إضافة مراحل جديدة وتحديد شروط الفتح ونقاط XP ومستوى الصعوبة.
- **إضافة التحديات:** اختيار نوع التحدي (اختيار من متعدد، صح وخطأ، ترتيب خطوات الخوارزمية، إكمال الكود، صيد الأخطاء، توقع المخرجات، توصيل المصطلحات الإنجليزية، وتحديات كتابة الأكواد الحية).
- **التحديث بدون إعادة بناء (Zero-Rebuild Content):**
  - حفظ المنهج بالكامل في قاعدة البيانات المحلية.
  - إمكانية تصدير المنهج كملف JSON كامل (Export).
  - إمكانية استيراد حزم المناهج الجديدة (Import) لتظهر للمستخدمين فوراً دون الحاجة لتحديث أو إعادة بناء ملف الـ EXE!
